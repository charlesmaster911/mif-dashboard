## 4. 듀오메이커 선반 배치 계산

### 선반 사양
- **선반 깊이**: 450 mm (듀오메이커 2열 전후 배치: 105mm × 2 + 여유 240mm)
- **선반 폭**: 컨테이너 내벽 기준 (단열재 100mm 제외)
- **단 간격**: 250 mm (듀오메이커 높이 170mm + 여유 80mm)
- **선반 단수**: 7단 (바닥 200mm 이격 ~ 천장 200mm 이격)

### MIF-20 냉동고 내 배치

| 항목 | 수치 |
|------|------|
| 냉동고 내부 유효 길이 | 2,400 mm |
| 냉동고 내부 유효 폭 | 2,152 mm (컨테이너 내벽 - 단열재 200mm) |
| 선반 1열당 듀오메이커 수 (가로) | 2,152 ÷ 182 = **11개** |
| 선반 깊이 방향 (전후) | **2열** |
| 1단당 듀오메이커 수 | 11 × 2 = **22개** |
| 총 단수 | **7단** |
| **선반 양쪽 (좌우벽)** | **2면** |
| 중앙 작업통로 | 600 mm |
| **총 듀오메이커 수** | 22 × 7 = 154개 (한쪽) → 양쪽: **~96개** (통로 확보 시 조정) |

### MIF-40 냉동고 내 배치

| 항목 | 수치 |
|------|------|
| 냉동고 내부 유효 길이 | 4,800 mm |
| 배치 방식 | 양쪽 벽면 선반 + 중앙 아일랜드 선반 |
| **총 듀오메이커 수** | **~144개** |
